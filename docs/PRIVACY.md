# 隐私说明

Interval 默认完全本地运行，不需账户、不含广告/遥测，不将使用数据传给开发者。

## 本地处理

启用监测后采样输入空闲时间、屏幕是否可用。单独开启键盘计数并获得输入监控权限后，仅计 keyDown 事件数量，不提取字符、键码或组合键。启用自动情境时瞬时读取前台应用 Bundle ID（立即分类）、窗口尺寸和默认输入设备运行状态。无屏幕截图、窗口标题、网页 URL、音频、视频或剪贴板读取。

原始计数与分类持续时间仅在内存，前台 Bundle ID 不作为使用历史落盘。用户主动填写的应用分类规则属于偏好设置，保存在本地。

保存最近 30 天每日汇总：屏幕使用估算秒数、按键总数、活动完成次数、提醒次数及偏好。文件在 `~/Library/Application Support/Interval/state.json`，0700 目录/0600 文件，未另行加密。可导出 JSON；导出是用户指定位置的普通文件，请自行管理。清除功能删除本应用记录、偏好与云端 Key，并停止监测；不会删除你已导出的文件或云服务方的日志。

## 可选云端

默认关闭。只有明确同意后，本地准备提醒时向用户填写的 HTTPS `/chat/completions` 地址发请求。发送字段：

| 字段 | 含义 |
|---|---|
| screen_minutes | 本轮连续屏幕使用估算分钟数 |
| keys_per_minute | 最近一分钟按键总数 |
| idle_seconds | 空闲秒数（最多 600） |
| context | 用户选择的情境枚举 |
| category | 前台应用类别枚举 |
| proposed_activity | 准备邀请的活动类型 |

不发送应用名称、Bundle ID、按键内容、网页/截图、历史每日记录或身份信息。网络通信仍可能使服务方获知连接的 IP 与时间。第三方留存规则取决于用户选择的服务。API Key 只存于 macOS 钥匙串，作为 Bearer Header 发往该地址，不导出、不写入 JSON。拒绝重定向，临时会话不保存缓存/Cookie；不关闭 HTTPS 验证。更改地址或模型会关闭云端，需再次同意。

用户关闭云端后取消在途请求并回到本地判断；已经传送给服务的数据无法通过本地开关撤回。

## 权限

输入监控用于可选按键计数，不需要辅助功能或屏幕录制权限。麦克风状态检测不录音，也不申请录音权限。登录启动使用 SMAppService，只有用户启用时注册，可在系统设置撤销。

## 能力界限

使用时长与情境均为估算；没有眼动/姿态/摄像头推断。活动完成只表示计时引导结束，不是运动验证或医疗判断。
