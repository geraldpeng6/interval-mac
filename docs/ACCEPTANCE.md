| 键盘输入频率与本地采样 | Sensors 只读计数、最近一分钟窗口与近期峰值 | 决策测试通过；真实 TCC 授权与按键事件待验证 |

| 每日可设置多次护眼与手腕活动 | 每项开关、频率、时长、每日目标，今日进度 | 配置与目标测试通过；原生控件编辑与重启持久化待验证 |
| 手腕、肩颈、盆底、站立组合 | RoutineItem、动作步骤、排序、分步计时、提示音 | 内容与来源已检查；完成、取消、暂停、组合流程待实际窗口验证 |

| 观影、会议、紧急工作保护 | 自动应用分类/全屏/输入设备线索；手动会议/观影；菜单栏稍后 | 核心保护测试通过；浏览器内容不读取，手动覆盖需实际抽查 |
